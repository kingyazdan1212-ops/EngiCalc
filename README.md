## 🚀 انتشار سریع روی GitHub Pages

1. ریپازیتوری جدید در GitHub بسازید
2. محتویات پوشه را آپلود کنید (`index.html` + `manifest.json` + `README.md`)
3. بروید به **Settings → Pages**
4. Source را روی شاخه `main` قرار دهید
5. چند ثانیه بعد سایت شما زنده است:
   ```
   https://YOUR_USERNAME.github.io/REPO_NAME
   ```

### نصب به عنوان اپ (PWA)
- در موبایل سایت را باز کنید
- از منوی مرورگر گزینه **Add to Home Screen** / **نصب برنامه** را بزنید

## 📱 تبدیل به اپ واقعی (Android / iOS)

با **Capacitor**:

```bash
npm create @capacitor/app
# نام: EngCalc
# package: com.yourname.engcalc

# فایل‌های این پروژه را در پوشه www کپی کنید
npx cap add android
npx cap sync
npx cap open android
```
